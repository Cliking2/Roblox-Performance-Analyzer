# Changelog

## 1.0.0-rc.1 — 2026-11-08

- Initial public release candidate of a standalone, read-only Roblox Studio plugin.
- Workspace and selection scanning, with duplicate-scope protection.
- Static candidate findings for precise collision meshes, particle emission and high object counts.
- Selection-on-click, grouped report, and manual demo scene.
- English documentation, French install guide, MIT license and validation checklist.

**Testing status:** not yet tested inside Roblox Studio. The release is intentionally marked as a candidate.
