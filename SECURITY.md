# Security policy

This project is a read-only Roblox Studio plugin that does not require any credentials or external services. Do not run third-party forks without reviewing their source.

For a potential security problem, please avoid publishing sensitive credentials or private assets. Contact the repository maintainer privately through a channel they have provided or open a public issue containing only non-sensitive reproduction details.

No response-time or vulnerability-fix guarantees are currently offered; this is an early-stage volunteer project.
